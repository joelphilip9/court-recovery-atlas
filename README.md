# Court Recovery Atlas

Court Recovery Atlas is a calm, practical check-in companion for athletes returning to sport. It helps users reflect on what changed, choose a cautious practice lane, and bring better questions to their clinician, athletic trainer, or coach.

**Live site:** https://hoops-recovery-index.vercel.app/

## What it includes

- CourtGuide: a guided recovery conversation with clear safety limits
- A one-minute readiness reflection for energy, comfort, and confidence
- Explainable **progress**, **repeat**, and **pull back** suggestions
- Clear prompts for symptoms that need professional attention
- Vetted education links for ACL, Achilles, and ankle injuries
- Private browser-only check-in history; no accounts or health data uploads

## Important note

Court Recovery Atlas is educational support, not medical diagnosis, treatment, or return-to-play clearance. A qualified clinician, athletic trainer, and coach should guide an athlete's individual return plan.

## Built with

Plain HTML, CSS, and JavaScript. No framework or backend is required.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server.
