Real-world use

Built to help fans, young athletes, parents, and coaches ask better questions.

For athletes and parents

Use the recovery guides to understand the difference between a few weeks, several months, and a true year-long rehab. That context matters when planning school, training, and expectations.

For coaches

The database can help frame return-to-play conversations more responsibly. Fast comeback stories exist, but they are not universal templates.

For everyone

This is educational only. Any inability to bear weight, major swelling, loss of motion, a visible deformity, or a pop with instability warrants evaluation by a clinician.
